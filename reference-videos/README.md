# Gameplay Reference Videos

Drop your downloaded gameplay references into this folder using VS Code Explorer.

Prefer MP4 (H.264) or WebM. Keep clips short and name them for the action, for example `m4-inspect.mp4`, `karambit-slash.mp4`, or `dust2-spawns.mp4`.

Include the source URL, creator, and relevant timestamps in a text file beside each clip. Only upload videos you have permission to use. References are for studying timing, movement, framing, and behavior, not copying copyrighted video into the game.

Video playback is not available to every assistant tool. When needed, local frames can be extracted for visual inspection. Do not commit large video files to the game deployment.

The supplied clips are now accompanied by a downloaded Quaternius animation preview and short official CS2 technical excerpts. [EXTERNAL-SOURCES.md](EXTERNAL-SOURCES.md) records their creators, source links, sampled ranges and reuse limits. Reference videos are not reusable game assets merely because they can be downloaded.
